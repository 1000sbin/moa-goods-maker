# 🍓 모아 굿즈메이커 (MOA Goods Maker)

투명 PNG를 올리면 **칼선·타공·고리·촉·화이트**를 자동으로 만들어주는 굿즈 제작 도구예요.
디자인/칼선/화이트 레이어를 나눠서 **PSD·PDF·SVG·PNG**로 저장해요. 인쇄소에 그대로 넣을 수 있어요.

**설치 없이 브라우저에서 바로** — 파일 하나만 열면 끝. 이미지는 서버로 안 올라가요, 전부 내 컴퓨터에서 처리돼요.

## 2.0 — 무엇이 달라졌나

- **6단계 흐름**: 제품 → 종류·이미지 → 칼선 → 부품 → 화이트/배경 → 저장. 왼쪽 레일에서 지난 단계로 자유롭게 돌아가요.
- **아이템 여러 개**: 이미지를 여러 장 올리거나(＋ 이미지 추가), 한 그림 안의 여러 개체를 **✂ 나누기**로 각각 아이템으로. **▦ 전체 보기**에서 한 대지에 자동 배치(끌어서 옮기기 가능)하고 PDF·PSD·SVG·ZIP **한 파일로** 저장.
- **스티커 = 대지 + 스티커**: 배경(단색·배경 파일)이 대지 전체에 깔리고 스티커는 반칼, 대지 외곽만 완칼로 나가요.
- **조립 굿즈**: 스핀 스탠드·쉐이커 키링·디오라마 3면·누들 스토퍼 프리셋. 판과 그림이 아이템으로 생기고, 촉↔슬롯·벽 퍼즐 결합이 자동으로 맞물려요.
- **👁 완성 보기**: 칼선 없이 판·화이트·그림을 겹친 실물 느낌 미리보기.
- 라이트/다크, 포인트 컬러 5색, 업데이트 확인·새 소식은 왼쪽 레일 하단에.

## 6단계로 끝나요

### ① 제품
**스티커 / 아크릴 / 조립 굿즈** 중 하나. 이후 단계에 그 제품에 맞는 것만 보여요 (스티커는 부품 단계가 없어요).

### ② 종류 · 이미지
- **종류** 고르기

  | 제품 | 종류 |
  |---|---|
  | 스티커 | 스티커 · 스티커 시트 |
  | 아크릴 | 키링 · 구멍 / 키링 · 고리 / 스탠드 · 받침 포함 / 스탠드 · 받침 없이 / 코롯토(일반 · 오뚝이) / 일반 아크릴 |
  | 조립 굿즈 | 스핀 스탠드 / 쉐이커 키링 / 디오라마 3면 / 누들 스토퍼 |

- 투명 PNG를 드래그해서 올려요 (JPG·흰 배경 이미지도 OK — ③에서 배경 제거 선택). **여러 장 올리면 아이템이 여러 개** 생겨요.
- **그림 실물 크기(mm)** 를 입력하면 해상도가 자동으로 맞춰져요. 클립스튜디오·포토샵 원고는 **DPI를 자동 감지**해요.
- **회전**: 임의 각도. 90/180/270°는 픽셀 무손실, 각도를 바꿀 때마다 원본에서 새로 돌려요.
- **대지 크기 고정**: 인쇄소가 "대지는 주문 사이즈와 동일하게" 요구할 때. 켜면 미리보기에서 그림을 드래그해 옮길 수 있어요.

#### 아이템 (미리보기 아래)
- 아이템 칩을 눌러 오가고, **＋ 이미지 추가**, **✂ 나누기**(한 그림 안의 개체를 각각 아이템으로 — 작은 파편은 가장 가까운 개체에 붙어요).
- 아이템이 2개 이상이면 **▦ 전체 보기**로 한 대지에 배치해 볼 수 있고, 끌어서 옮기면 자동 배치가 덮어쓰지 않아요 (↺ 자동 배치로 복귀).

### ③ 칼선
- **여백(mm)**: 그림 바깥으로 얼마나 띄울지. 아크릴은 보통 2~3mm. 스티커는 촘촘/보통/넉넉 프리셋
- **부드럽게 / 꼭지점 둥글리기(mm) / 틈 좁히기(mm) / 내부 구멍 메우기**
- **앵커 미리보기 · 앵커 수 최소화**
- 조립 굿즈의 **판**은 여기서 판 모양을 정해요 — 규격 도형(원·사각·둥근사각) / **인쇄소 가이드 파일**(PNG·SVG, 투명 구멍은 그대로 칼선) / **그림 모양**(그림 실루엣에서 칼선)

### ④ 부품 (아크릴·조립 굿즈만)
- **타공 지름 / 고리 벽 두께** — 미리보기에서 구멍·고리·촉을 **직접 드래그**
- **스탠드**: 촉 너비·높이, 받침 크기·모양, 슬롯 위치. 촉은 발끝이 아니라 **촉을 받칠 수 있는 넓은 구간** 아래에 자동으로 놓여요
  - 받침 만드는 방법: **도형 자동 생성** / **별도 이미지 올리기**(실루엣 칼선 + 받침에도 인쇄) / **지금 그림에서 잘라내기**
  - 슬롯은 받침에서 살이 가장 두꺼운 줄에, 여러 명이면 촉 간격 유지, 벽이 얇으면 캡슐 모양으로 살을 붙여 보정
- **코롯토**: 일반(평평한 바닥) / **오뚝이**(무게중심을 계산해 둥근 바닥 — 흔들리다 제자리로). 미리보기에 무게중심·접지점이 표시되고, 안 서면 ⚡ 자동 보정
- **도형**(집게·자석 자리): 프리셋(집게 일반 ⌀32 / 와이드 55×32 / 자석 ⌀40) 또는 직접. 어느 아크릴 종류에나 얹을 수 있어요
- **조립 굿즈 판**: 아래 촉(개수·폭·바닥 두께), 바닥의 어느 쪽에 서는지, **벽끼리 퍼즐 결합**(손가락 수 · A/B). 바닥판·덮개판은 꽂히는 아이템의 촉에 맞춰 슬롯·가장자리 홈이 **자동으로** 파여요

### ⑤ 화이트 (아크릴) / 배경 (스티커)
- **아크릴 화이트**: 그림 그대로(자동) 또는 **직접 만든 파일**(부분 화이트·홀로그램 연출, 업로드 시 불투명 % 표시). 여백(mm), 형식(벡터/이미지), 미리보기 토글
  - 실제로 내보낼 화이트가 그림과 얼마나 어긋나는지 **실측**해서 표시해요 (평균 이탈 mm · 빠짐/넘침 mm²)
  - 농도(그라데이션)가 있는 화이트는 벡터로 못 만들어 이미지로 나가요 — 내보낼 때 알려줘요
- **스티커 배경**: 배경 인쇄 켜기/끄기, **단색** 또는 **배경 파일**. 배경은 대지 전체에 깔리고 스티커는 반칼, 대지 외곽만 완칼. 배경 파일을 올리면 대지 크기가 파일 크기가 돼요. 투명 스티커로 여백을 비우려면 배경 인쇄를 끄세요

### ⑥ 저장
- **PSD**(레이어 + 벡터 패스) · **PDF**(디자인 / 칼선 / 화이트 페이지, 칼선·화이트는 패스) · **SVG**(칼선 벡터) · **PNG 묶음 ZIP**
- **PSD 색상 모드** RGB/CMYK, **칼선 색상(PDF)** RGB / M100 / C100 / K100
- **여러 아이템**: 한 대지에 모아서(자동 배치, 아이템 간격 mm) / 현재 아이템만
- **받침을 별도 대지로 저장**: 본체와 받침이 각자 자기 크기의 대지로 (PDF 페이지 분리 · ZIP 폴더 분리 · SVG/PSD 파일 분리)
- **저장 폴더 지정**: 지정하면 매번 묻지 않고 바로 저장 (Chrome·Edge·데스크톱 앱)

## 자주 묻는 것

**Q. 굿즈 실물 크기는 어디서 봐요?**
미리보기 아래 정보줄의 **"굿즈 실물"** — 여백·고리까지 포함된, 손에 쥘 아크릴의 진짜 크기예요. 발주서에 이 숫자를 쓰세요.

**Q. 클립스튜디오에서 만든 크기랑 달라요**
원고가 350dpi인데 도구가 300dpi로 읽으면 16.7% 차이 나요. ②에서 **DPI 자동 감지** 표시를 확인하고, 안 맞으면 직접 입력하세요.

**Q. 고리가 완벽한 원이 아니에요**
정상이에요. 실제 고리가 걸리는 **타공 구멍은 정원**이고, 바깥 실루엣은 몸통과 이어지느라 살짝 물방울형이 돼요.

**Q. 화이트가 그림보다 살짝 커요**
의도된 거예요. 인쇄 정합 오차를 흡수하려고 넉넉하게 덮어요. 신경 쓰이면 **화이트 여백을 −0.2mm** 정도 주세요.

**Q. 스탠드 촉이 이상한 데 붙어요**
④ 부품에서 촉을 드래그해서 옮기세요. 위로 끌면 엉덩이·몸통 쪽까지 올라가요.

**Q. 조립 굿즈 치수가 인쇄소랑 달라요**
판 두께·촉·손가락 수는 판 패널에서 바꿀 수 있고, 인쇄소 가이드 파일이 있으면 **가이드 파일 가져오기**로 그 규격 그대로 쓰는 게 제일 확실해요. 앱에 특정 인쇄소 규격을 내장하지 않아요.

**Q. 모바일에서 직접 만든 화이트가 무시돼요**
1.7.0에서 고쳤어요 (같은 파일을 다시 고르면 무시되던 파일 선택기 버그). 업로드하면 불투명 %가 표시되니 0%면 알려주세요.

**Q. 일러스트레이터로 넘기고 싶어요**
**PSD**(디자인·화이트 픽셀 + 칼선 벡터 마스크)를 열고, 재단선은 **SVG**를 따로 가져와 얹으면 제일 깔끔해요. CMYK 문서가 필요하면 ⑥에서 CMYK PSD로 받으세요.
